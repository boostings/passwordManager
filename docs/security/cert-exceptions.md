# CERT exceptions ledger

Every scanner suppression (SpotBugs exclude, `@SuppressWarnings("PMD.…")`, Semgrep `nosemgrep`)
must have a row here. Each one is as narrow as the tool allows (one class, one method, one rule)
and needs security-owner sign-off before the milestone closes.

| ID | Rule | Location | Justification | Status |
| --- | --- | --- | --- | --- |
| CE-001 | FindSecBugs `CIPHER_INTEGRITY` (CWE-353) | `pm.crypto.KeyWrap#initCipher` (`tools/cert-rules/spotbugs-exclude.xml`) | False positive. The transformation is `AES/KWP/NoPadding` (RFC 5649 AES Key Wrap with Padding, ADR 0004). KWP is a deterministic authenticated-encryption mode: unwrap verifies the alternative initial value and the padding length, and any wrong KEK or modified byte fails with a `GeneralSecurityException`, mapped to `AUTH_FAILED`. The detector only treats GCM as integrity-protecting. Covered by `KeyWrapTest` (RFC 5649 vectors, wrong-KEK and bit-flip properties). | Pending security-owner sign-off |
| CE-002 | PMD `DoNotUseThreads` (TPS00-J) | `pm.tui.IdleLock` (class-level `@SuppressWarnings("PMD.DoNotUseThreads")`) | False positive against the CERT intent. TPS00-J requires using executors instead of raw threads; PMD 7's rule also reports `ExecutorService`/`Executors`. `IdleLock` takes the §2 `ScheduledExecutorService` and creates no raw `Thread`. Suppression is limited to this one class. | Pending security-owner sign-off |
| CE-003 | SpotBugs `EI_EXPOSE_REP`, `EI_EXPOSE_REP2` (OBJ05-J, OBJ06-J) | `pm.vault.CreatedVault`, `pm.tui.CreatedSession` (`tools/cert-rules/spotbugs-exclude.xml`) | Intentional. These records hand the caller a live handle to the unlocked vault/session plus the one-time recovery key; ownership transfers to the caller, who closes both. A defensive copy of an unlocked vault is meaningless. SpotBugs treats `Vault`/`Session` as mutable because of `put`/`remove`. Restricted to these two classes and two patterns. The `CreatedVault` row was added by Lane E against the §2 stub; Lane C inherits it when replacing the file. | Pending security-owner sign-off |
| CE-005 | SpotBugs `DM_GC` (performance) | `pm.crypto.Kdf#collectGarbage` (`tools/cert-rules/spotbugs-exclude.xml`) | Intentional. Before running Argon2, `Kdf.argon2id` refuses with `BAD_PARAMS` when `memoryKiB * 1024 * 11/10` exceeds the free heap (max minus `totalMemory() - freeMemory()`), so a hostile header cannot exhaust the heap. "In use" counts unreachable garbage, such as the Argon2 blocks `Kdf.tune` just timed, so on a small heap (123 MiB) the first figure wrongly refuses the floor. `System.gc()` runs only when the first figure falls short, once, and the check is then repeated. The match is name-based on `collectGarbage`; renaming the method breaks it. | Pending security-owner sign-off |
